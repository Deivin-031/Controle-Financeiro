# Controle Financeiro — v2 de teste
Firebase configurado. Mantenha as regras de segurança já publicadas. Envie os arquivos à raiz do GitHub Pages. Cadastro por e-mail e senha; nome de usuário salvo localmente após cadastro ou login por e-mail. Em outro aparelho, entre primeiro por e-mail. Nomes de usuário não são globalmente exclusivos nesta versão. Não há índice público de e-mails. Biometria e notificações automáticas ainda não implementadas. Teste com dados fictícios; não auditado. Não há sincronização offline nem proteção contra edições simultâneas. Cartões registram faturas diretamente.
